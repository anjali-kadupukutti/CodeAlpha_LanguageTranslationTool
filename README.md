# Language Translation Tool

## About
A Language Translation Tool built using Python as part of CodeAlpha AI Internship.

## Features
- Simple and clean user interface
- Supports 10+ languages
- Powered by Google Translate API
- Copy translation button

## Technologies Used
- Python 3.10
- Tkinter (GUI)
- deep-translator (Google Translate API)

## How to Run
1. Install library: pip install deep-translator
2. Run: python translation_tool.py

## Languages Supported
English, Hindi, Telugu, Tamil, French, Spanish, German, Arabic, Chinese, Japanese
